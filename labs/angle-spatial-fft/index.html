Δφ = −2π(d/λ)sinθ,   u=(d/λ)sinθ.

Key idea: a uniform linear array samples a sinusoid in space. Angle changes the spatial frequency. The FFT is therefore being used on antenna index in the same way it was used on time samples earlier in the book.

Important: the FFT grid is uniform in spatial frequency, not in angle. The nonlinear mapping θ=sin⁻¹(u/(d/λ)) stretches the angle grid near endfire.
