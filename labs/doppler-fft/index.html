Key idea: increasing Tr improves the nominal velocity grid for fixed M, but it simultaneously reduces the unambiguous velocity interval. The slow-time spectrum is periodic, so a peak that crosses one velocity boundary reappears at the opposite boundary. Zero padding only samples the same finite-record spectrum more densely.
