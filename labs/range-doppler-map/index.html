Idealized Range-Doppler response

ΔR≈c/(2B),   Δv≈λ/(2MTᵣ),   |v|<λ/(4Tᵣ).

Key idea: a target pair that overlaps along one axis may separate along the other. The Doppler axis is periodic because slow time is sampled once per chirp; responses that cross one velocity edge wrap to the opposite edge. The map is intentionally idealized and adds target powers rather than modeling every coherent phase, hardware, and windowing detail.

Self-contained HTML + JavaScript. No external library required.
